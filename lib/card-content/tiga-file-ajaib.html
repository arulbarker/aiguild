File 1 — CLAUDE.md Global

Ini "identitas permanen" kamu yang dibaca Claude di SETIAP project.

Lokasi penyimpanan

  • Siapa kamu & apa yang kamu bangun
  • Cara komunikasi yang kamu mau
  • Tech stack yang kamu pakai
  • Cara kerja yang kamu suka
⚙️ Standar Profesional — JANGAN diubah
  • Prinsip local-first
  • Git workflow
  • Testing 3 lapis
  • Keamanan & Monitoring
  • Environment dev vs prod
"Bagian pribadi = tentang kamu. Bagian standar = best practice yang sudah teruji — jangan diutak-atik."

Cara Termudah — Biarkan AI yang Mewawancara

Kamu tidak perlu isi template manual. Cukup minta Claude mewawancarai kamu.

Prompt yang dipakai
"Aku punya template CLAUDE.md ini. Tolong tanya aku satu per satu untuk mengisi semua bagian [dalam kurung siku], lalu berikan versi final yang lengkap. [paste isi template CLAUDE.md]"
Yang akan terjadi
  • Claude bertanya satu per satu: "Siapa kamu?" · "Tech stack apa?" · "Gaya komunikasi?"
  • Kamu jawab santai → Claude rangkum jadi file final
  • Simpan ke ~/.claude/CLAUDE.md
Analogi: seperti isi formulir didampingi petugas. Kamu tidak perlu paham tiap kolom — petugas tanya, kamu jawab, selesai.
"5 menit dipandu AI — lebih baik dari 15 menit bingung sendiri."

PENTING — Bagian Standar Jangan Disentuh

Bagian "Standar Profesional" berisi best practice yang sudah teruji: local-first, git workflow, testing 3 lapis, keamanan, monitoring, pemisahan dev vs prod.

⚠️ Jangan ubah, karena
  • Sudah teruji dari pengalaman nyata
  • Saling terkait satu sama lain
  • Kalau diutak-atik — sistem bisa rusak
  • Melindungi kamu dari kesalahan fatal
Yang BOLEH
  • Isi bagian pribadi
  • Pakai bagian standar apa adanya
Yang TIDAK boleh
  • Hapus / ubah aturan standar
  • "Sederhanakan" karena merasa ribet
"Bagian standar itu seperti rem mobil. Kamu tidak paham cara kerjanya — tapi jangan pernah copot."

File 2 — Magic Prompt Init (Project Baru)

Dipakai saat kamu mulai project dari NOL. Dijalankan SEKALI — setelah itu otomatis.

Apa yang dilakukan
  • Scan semua file & brainstorming yang ada
  • Buat struktur folder .claude/ yang rapi
  • Isi semua file aturan & dokumentasi
  • Rangkum ide jadi product-spec
  • Setup keamanan & gitignore
📁 .claude/ ├── CLAUDE.md (daftar isi project) ├── rules.md (aturan project) ├── SESSION.md (status harian) ├── skills/ (SOP cara kerja) └── docs-library/ (dokumentasi)
"Satu prompt — project langsung terstruktur seperti dikerjakan tim profesional."

Cara Pakai Magic Prompt Init

Urutan untuk project BARU:

  1. Brainstorming dulu dengan Claude — tuangkan semua ide aplikasimu
  2. Jalankan /init di Claude Code — Claude scan & buat CLAUDE.md awal
  3. Paste Magic Prompt Init — copy seluruh isi → paste ke Claude
  4. Claude kerjakan semua langkah — buat struktur, isi file, setup keamanan
  5. Review laporan Claude — Claude lapor apa yang sudah dibuat
  6. Konfirmasi → baru mulai coding — sistem sudah siap, semua otomatis
Penting: Magic Prompt Init akan BERHENTI dan minta konfirmasi sebelum mulai coding. Ini disengaja — agar kamu cek dulu semuanya benar.
"Jalankan sekali di awal — nikmati struktur rapi selamanya."

File 3 — Magic Prompt Existing (Project Lama)

Dipakai untuk project yang SUDAH berjalan tapi belum punya struktur rapi.

Bedanya dengan Init
  • Init = untuk project kosong dari nol
  • Existing = untuk project yang sudah ada isinya
Yang membuat ini AMAN
  • TIDAK merusak apapun yang sudah ada
  • TIDAK menghapus tanpa izin
  • Konfirmasi di setiap langkah
  • Sifatnya menambah, bukan membongkar
"Punya project lama yang berantakan? File ini merapikannya — tanpa risiko merusak yang sudah jalan."
11 / 16
🛡️

Kenapa Magic Prompt Existing Aman Dipakai

Ketakutan terbesar: "Project saya sudah jalan, takut rusak kalau diutak-atik." File ini dirancang khusus untuk menghilangkan ketakutan itu.

  • 🛡️ Audit dulu, eksekusi belakangan — Claude lapor kondisi sebelum ubah apapun
  • 🛡️ Berhenti di setiap langkah — minta konfirmasi sebelum lanjut
  • 🛡️ Tidak menimpa file yang ada — file lama dibiarkan, hanya menambah baru
  • 🛡️ Additive, bukan destructive — menambah struktur, bukan membongkar
  • 🛡️ Konfirmasi sebelum pindah/hapus — tidak ada yang dihapus tanpa izinmu
"Dibuat dengan prinsip: lebih baik bertanya dua kali daripada merusak satu kali."

Apa Itu Struktur Library .claude/

"Setiap project jadi perpustakaan rapi — Claude tahu persis di mana cari informasi."

Bonus — Kata Kunci Ajaib yang Otomatis

Setelah setup, kamu punya "kata kunci ajaib" yang memicu aksi otomatis Claude.

🔑 "tutup sesi"

Claude jalankan checklist akhir sesi — commit, update SESSION.md, rapikan sebelum berhenti kerja.

🔑 "sync docs"

Claude audit semua dokumen — cek mana yang outdated, mana file liar, rapikan struktur.

🔑 "push ke prod"

Claude jalankan SOP deploy aman — cek testing, cek database, baru deploy.

🔑 "rollback"

Claude balikkan ke versi stabil saat production bermasalah.

"Satu kata kunci — serangkaian aksi profesional berjalan otomatis."

Alur Lengkap — Dari Terima File Sampai Coding

  1. Terima 3 file dari bootcamp
  2. Setup CLAUDE.md Global (sekali seumur hidup) — paste template + minta Claude wawancara → simpan ke ~/.claude/CLAUDE.md
  3. Mulai project — pilih situasimu:
    • Project BARU → brainstorming → /init → paste Magic Prompt Init
    • Project LAMA → paste Magic Prompt Existing
  4. Claude setup struktur library otomatis
  5. Review & konfirmasi laporan Claude
  6. Mulai coding — sistem jalan otomatis
Setelah ini: setiap sesi Claude langsung paham project, ikuti standar profesional, dan tidak perlu brief ulang.
"Setup sekali di awal — profesional selamanya."
